# Multiomics_mdd
This repository contains main scripts related to paper "Plasma multimodal molecular profiling of incident depression in middle-aged and older adults".

Cox model: Cox.R

Logistic model: Logistic.R

GO pathway enrichment: Enrichment.R

Network analysis (Louvain): Network_Louvain_module.py

AI multimodal prediction: Prediction_model

Two-sample Mendelian randomization: MR.R
